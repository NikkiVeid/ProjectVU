# Порядок запуска


#### 1 - Установить все зависимости из ```requierements.txt```.

#### 2 - Скачать таблицу по матпомощи после обработки текущего месяца

#### 3 - Через скрипт ```parse_sheet.py``` получить таблицу, где хранятся все заявления за текущий месяц.

Как запускать ```parse_sheet.py``` ? 

```
python3 parse_sheet.py --prefix 02 --source source.xlsx --list-file 1.txt --target result.xlsx
```

где:

* ```--prefix``` - номер месяца, который обработался

* ```--source``` - путь на исходную таблицу

* ```--list-file``` - путь на .txt файл, где хранятся листы, которые нужно извлечь из изначальной таблицы в результирующую таблицу
 
* ```--list-file``` - путь на результирующую таблицу

#### 4 - через скрипт ```main.py``` запустить генерацию .pdf


Как запускать ```main.py``` ? 

```
python3 main.py result.xlsx
```
где ```result.xlsx``` - результирующая таблица
